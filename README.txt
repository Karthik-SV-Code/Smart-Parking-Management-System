Smart Parking App v2.3 - Admin Slot Manager (Professional UI)
Features:
- Left vertical sidebar navigation (no emojis/icons)
- CardLayout for main content (Home, Slots, Manage Slots (admin), Bookings, Profile)
- Admin can Add/Delete slots via Manage Slots panel (Delete fails if slot has active bookings)
- 6 default free slots created on first run
- Inline status messages instead of unnecessary popups
- Larger fonts and refined spacing for a professional look

Run:
1. Extract ZIP and open src/
2. javac -cp . *.java
3. java Main
